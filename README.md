# Java 练习项目集合

这是我在 2018-2021 年间的 Java 学习项目集合，包含 Servlet、JDBC、多线程等内容的练习代码。

## 项目列表

### FirstServlet
Java Servlet 基础练习项目，学习 Web 开发基础。
- 用户注册、查询等功能
- JDBC 数据库操作
- 时间：2020年

### JDBCprojectDemo
JDBC 数据库连接练习项目。
- 包含多个 JDBC 测试用例
- 数据库工具类封装
- 时间：2020年

### Lab
实验室管理系统（较完整的项目）。
- 管理员管理、新闻发布、成就记录、团队管理
- 文件上传下载功能
- MVC 架构（Servlet + DAO + Entity + Service）
- MD5 加密、登录过滤器
- 时间：2020年

### 练习
Java 基础练习代码。
- 几何图形面积计算（多态、比较器）
- 多线程练习
- 票务系统模拟
- 时间：2018-2019年

## 技术栈
- Java SE
- Servlet
- JDBC
- 多线程
- Eclipse IDE
